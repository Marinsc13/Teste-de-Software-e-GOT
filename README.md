# 🛒 Testes de Software - Carrinho de Compras

Projeto desenvolvido para aplicar conceitos de **Testes de Software**, utilizando JavaScript, Node.js e Jest.

O projeto simula o cálculo do valor total de um carrinho de compras, considerando subtotal, desconto por cupom, regra de frete, arredondamento e validação de entradas.

---

## 📌 Sobre o Projeto

O sistema possui uma função chamada `calcularTotal(itens, cupom)`, responsável por calcular o valor final de uma compra.

Durante o desenvolvimento, foram identificados e corrigidos problemas relacionados às regras de negócio do carrinho, incluindo:

- Validação de quantidade e preço;
- Aplicação de desconto;
- Regra de frete grátis;
- Arredondamento do valor final;
- Validação de carrinho vazio.

A função realiza a validação do carrinho e calcula o subtotal multiplicando o preço pela quantidade de cada item. :contentReference[oaicite:1]{index=1}
